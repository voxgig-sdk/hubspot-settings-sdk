POST /settings/currencies/2026-09/exchange-rates/batch/create

Operation ID: post-/settings/currencies/2026-09/exchange-rates/batch/create.

Authentication: oauth2 (oauth2).

Request body

application/json

Property Type Required Description
inputs array of object Yes An array of ExchangeRateCreateRequest objects, each representing the details required to create a single exchange rate. This includes properties like fromCurrencyCode, conversionRate, and effectiveAt.
inputs[].conversionRate number Yes The conversion rate between the to and from currency code of this exchange rate.
inputs[].effectiveAt string (date-time) No The date the exchange rate is in effect.
inputs[].fromCurrencyCode enum: AED, AFN, ALL, AMD, ANG, AOA, ... Yes This represents the three-letter currency code (such as USD for US Dollar) of the currency you want to convert from.

Responses

201: successful operation

results[].conversionRate number Yes The conversion rate between the to and from currency code of this exchange rate.
results[].createdAt string (date-time) Yes The date the exchange rate was created.
results[].effectiveAt string (date-time) Yes The date the exchange rate is in effect.
results[].fromCurrencyCode enum: AED, AFN, ALL, AMD, ANG, AOA, ... Yes This represents the three-letter currency code (such as USD for US Dollar) of the currency you are converting from.
results[].id string Yes A unique identifier for the exchange rate
results[].toCurrencyCode enum: AED, AFN, ALL, AMD, ANG, AOA, ... Yes This represents the three-letter currency code (such as USD for US Dollar) of the currency you are converting to.

results[].visibleInUI boolean Yes This indicates if the exchange rate is shown in the MultiCurrency settings page.
