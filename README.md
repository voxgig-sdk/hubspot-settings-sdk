# hubspot-settings-sdk

SDK for the **HubSpot Settings API**, generated by
[Voxgig sdkgen](https://github.com/voxgig/sdkgen).

HubSpot publishes one OpenAPI document per API. This SDK covers the 4
API(s) HubSpot publishes under **Settings**, merged into a single definition —
24 paths, 58 component schemas. See
[`.sdk/def/PROVENANCE.md`](./.sdk/def/PROVENANCE.md).
